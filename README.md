# Azure Storage Account Lab
 
## Project Overview
 
In this project I demonstrate how to create and configure an Azure Storage Account, create a Blob Container, upload files, and explore storage redundancy options in Microsoft Azure.
 
## Objective
 
The goal of this project was to gain hands-on experience with Azure Storage services and understand how data is stored, secured, and replicated in Azure.
 
## Azure Services Used
 
- Azure Storage Account
- Azure Blob Storage
- Azure Resource Group
- Azure IAM (Access Control)

## Storage Redundancy Options Learned
 
### LRS
Stores multiple copies of data within a single Azure datacenter.
 
### ZRS
Stores data across multiple availability zones in the same region.
 
### GRS
Replicates data to a secondary Azure region.
 
### GZRS
Provides both zone redundancy and regional redundancy.
